# Dnyaneshwari's Portfolio Website

A responsive portfolio built using plain HTML, CSS and JavaScript.

## Files
- `index.html` - website content
- `style.css` - colours, layout and responsive design
- `script.js` - mobile navigation, footer year and email form behaviour
- `assets/` - your photo, project screenshots and resume

## Run locally
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Personalize before publishing
1. Search `YOUR_USERNAME` in `index.html` and replace it with your GitHub/LinkedIn usernames.
2. Replace `YOUR_EMAIL@example.com` in both `index.html` and `script.js`.
3. Add `assets/profile.jpg`.
4. Add project screenshots `assets/project1.png` and `assets/project2.png`.
5. Add your resume as `assets/resume.pdf`.
6. Replace sample project links, descriptions, skills and education details with accurate information.
7. Check every link and test on mobile before publishing.

## Add another project
Copy an entire `<article class="project-card"> ... </article>` inside the `projects-grid` section in `index.html`, then edit its title, description, screenshot, tags and link.

## Contact form note
The form uses `mailto:` to open the visitor's email app. It does not send messages directly from the website or store them. A backend or form service is needed for a hosted form that receives submissions.

## Publishing
This is a static website and is suitable for GitHub Pages or other static hosting services.
